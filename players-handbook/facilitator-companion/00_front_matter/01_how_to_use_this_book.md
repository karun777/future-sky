# How to Use This Book

This book is not meant to be read cover to cover.

It is meant to be *returned to*.

Use it the way you would use a good tool kit: keep it nearby, open it when something feels uncertain, and trust that you already know more than you think.

---

## This Is a Reference, Not a Curriculum

You do not need to memorise this book.

You do not need to master every system before running play.

Instead:
- Read sections as questions arise
- Skim chapters before sessions
- Revisit parts that resonated
- Ignore what you do not need yet

Future Sky rewards familiarity, not expertise.

---

## Start With Tone, Not Rules

If you are new to facilitating *Future Sky*, begin with:
- **Tone, pacing, and pressure**
- **Soft time vs hard time**
- **Consequence and follow-through**

These shape play more than any single mechanic.

---

## Read Sideways

This book is intentionally modular.

You may:
- Jump between sections
- Read one chapter per session
- Use tables and templates without context
- Adapt examples freely

No section assumes the others have been read first.

---

## During Play

During a session, this book can help you:
- Clarify stakes before a roll
- Decide when to escalate pressure
- Resolve uncertainty without stalling
- Translate player intent into world response

If consulting the book slows play, make a ruling and move on.  
You can always revisit later.

---

## Between Sessions

Between sessions, this book supports:
- Reflecting on what changed
- Tracking unresolved threads
- Planning pressure windows
- Preparing factions, events, or locations

Preparation focuses on *conditions*, not outcomes.

---

## Mark It Up

This book expects to be:
- Highlighted
- Annotated
- Modified
- Argued with

Add notes specific to your table.
Cross out what does not apply.
Rewrite sections if needed.

Ownership improves play.

---

## Use the Examples Generously

Examples are included to:
- Show intent
- Model tone
- Demonstrate flow

They are not prescriptions.

If an example conflicts with your table’s reality, the table wins.

---

## You Are Allowed to Pause

If something feels unclear or heavy:
- Pause the scene
- Clarify intent
- Reframe stakes
- Ask the table

Facilitation is not about never stopping — it is about stopping *well*.

---

## A Final Reassurance

If you are asking:
> “Am I doing this right?”

You probably are.

If the players are engaged, making choices, and reacting to consequences, the system is working.

This book exists to support that — not to replace it.
