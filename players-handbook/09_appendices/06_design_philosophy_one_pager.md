# Design Philosophy: One Page

*Future Sky* is a game about agency under pressure.

It is not about optimisation, power accumulation, or winning conditions. It is about how people act when time, systems, and consequence push back.

This page explains the intent behind the rules.

---

## Agency Over Authority

Rules exist to support player choice, not replace it.

If a rule blocks meaningful agency, it should be questioned.
If a ruling preserves agency, it is valid.

The table is the final authority.

---

## Consequence Over Punishment

Failure is not a dead end.
Success is not free.

Every action leaves a trace — social, narrative, or systemic. Consequence creates continuity without removing possibility.

The world remembers, but it does not seek revenge.

---

## Familiar Shapes, New Context

*Future Sky* uses recognisable structures:
- d20 resolution
- classes
- skills
- turns
- progression

These exist so players can enter quickly.

What changes is *why* they matter.

Context reshapes function.
Era reshapes expression.
Growth reshapes identity.

---

## Time Is a Tool

Time is not always linear, and urgency is not always constant.

Soft time supports exploration.
Hard time creates pressure.
Windows of consequence give meaning to choice.

The game flows between these states intentionally.

---

## Systems Are Alive

The world is not static.

Factions act.
Threads evolve.
Events trigger without permission.
Structures respond to neglect or care.

Players are not the centre of the universe — but they are never irrelevant.

---

## Power Requires Alignment

Power without alignment creates distortion.

Chakras, mana, strain, and mastery exist to reflect this truth mechanically and narratively.

Growth is possible.
Shortcutting is costly.
Balance is earned.

---

## Death Is Not the End

Loss matters.
Return is possible.
Change is inevitable.

Death marks transition, not erasure.

---

## The Cube Exists to Break Rules Carefully

The Cube is a deliberate exception engine.

It exists so that:
- memory persists
- systems bend without collapsing
- narrative can override mechanics transparently

The Cube is not a loophole.
It is a responsibility.

---

## Modularity Is a Feature

Not every table wants the same weight.

Optional modules exist to tune:
- complexity
- pressure
- meta interaction
- pacing

The core remains stable.

---

## The Table Is a Shared Space

This game assumes:
- trust
- conversation
- consent
- reflection

If something feels wrong, pause.
If something breaks flow, simplify.
If something excites the table, follow it.

---

## What This Game Is Asking

*Future Sky* asks players:

- What do you choose when it matters?
- What do you protect when it costs something?
- What do you become over time?

The rules exist to help you answer honestly.

That is the game.
