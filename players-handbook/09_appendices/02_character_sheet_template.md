# Character Sheet Template

This template describes the *logical structure* of a Future Sky character sheet.

It is system-facing rather than format-specific, meaning it can be implemented as:
- Paper sheet
- Digital form
- Discord bot profile
- App or web UI

Not all fields are required at all times. Some unlock through play.

## Using This Sheet

This sheet is:
- A record
- A mirror
- A tool

It is not a contract.

If the sheet and the fiction disagree, pause and talk it through.  
The sheet should follow the story — not replace it.
