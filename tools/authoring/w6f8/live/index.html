        Commands

        Type in the COMMANDS box and press Enter. The ! prefix is optional.

        • look — return to the current room view
        • go west — move through an available exit
        • inspect panels, inspect display, inspect booking, inspect wardrobe — attend to an offered detail
        • wardrobe — view the discovered wardrobe
        • inspect Freeform Attire — examine an outfit
        • uniform freeform — choose and wear a first outfit, once only
        • wear Leather Jacket — wear clothing you carry
        • fit, inventory, sheet — view your character panels

        Other commands remain available in Discord. Viewing panels does not pause the world or prevent idle return.
