# Future Sky — Quickstart

1) Say hi in **#arrival-lounge** (optional but nice).
2) Use your commands anywhere, but expect replies in your **fs-<name>** run channel.
3) Try:
- `!look`
- `!go <direction>` (or `!move <direction>` if enabled)
- `!sneak`
- `!attack <enemy>` (if something hostile is present)

If something feels broken, ask in **#general** and paste the error line.
