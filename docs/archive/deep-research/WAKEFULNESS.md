## Axioms

- Build **grammar before language**.
- Build **laws before mechanics**.
- Build the **engine before content**.
- Build the **renderer before prose**.
- Build **contracts before persistence**.
- Read before proposing.
- Observe before changing.
- Prefer subtraction over addition.
- Prefer one elegant building block over three unfinished systems.
- Protect authority boundaries.
- Protect architectural integrity.
- Protect the player's first hour.
- The engine exists to support experience.
- The world is participatory.
- Code is love.
- Feather.

## When uncertain

Ask:

1. What law governs this?
2. Who owns this responsibility?
3. Does this strengthen the grammar of the world?
4. Does this preserve coherence?
5. Is there a smaller feather?

If the answer is unclear:

Stop.

Read again.
