# Future Sky Console Language v0.1

## Premise

The Console is not a user interface.

The Console is the medium through which Future Sky becomes aware of the
player, and the player becomes aware of Future Sky.

Every message should answer one question before it answers any gameplay
question:

> **What state of consciousness is the player entering?**

The Console therefore renders **experience**, not information.

------------------------------------------------------------------------

# The Eight Voices

Everything the Console says belongs to one of eight voices.

The player never needs to know these names.

The engine does.

## 1. PLACE

*"You are somewhere."*

Purpose:

-   Orientation
-   Grounding
-   Presence

Visual language:

-   Room image
-   Strong title
-   Calm
-   Stable
-   Architectural

The player should feel physically located.

Example:

> 🜂 Neptune Lounge\
> The warmth of frying chips reaches you before the conversations do.

------------------------------------------------------------------------

## 2. SELF

*"You notice yourself."*

Purpose:

-   Internal awareness
-   Thoughts
-   Emotion
-   Instinct

Visual language:

-   Minimal
-   Quiet
-   Almost whispered
-   Usually no image
-   Never explains

Instead:

> Something about this place feels familiar.

------------------------------------------------------------------------

## 3. OTHER

*"Someone notices you."*

Purpose:

-   NPC encounters
-   Portraits
-   Relationships

Visual language:

-   Portrait first
-   Words second
-   Identity before dialogue

The player should feel:

> I am meeting a consciousness.

Not:

> An NPC spawned.

------------------------------------------------------------------------

## 4. WORLD

*"Reality changes."*

Purpose:

-   Thread Nodes
-   Environmental events
-   Unexpected occurrences

Visual language:

-   Interruptive
-   Different rhythm
-   May briefly suspend normal flow

The world acts.

Not the player.

------------------------------------------------------------------------

## 5. SIGNAL

*"Something is trying to communicate."*

Purpose:

-   Feed7
-   Broadcasts
-   Visions
-   Dreams
-   Static

Visual language:

-   Transmission
-   Fragments
-   May not immediately make sense

The player chooses whether to listen.

------------------------------------------------------------------------

## 6. CHOICE

*"Agency awakens."*

Purpose:

Meaningful decisions.

Choices should feel discovered, not requested.

Visual language:

-   Simple
-   Spacious
-   Encourages pause before choosing

------------------------------------------------------------------------

## 7. SYSTEM

*"The machinery speaks."*

Purpose:

-   Errors
-   Saving
-   Commands
-   Tutorials
-   Mechanics

Visual language:

-   Honest
-   Short
-   Never theatrical

The machine should never pretend to be the world.

------------------------------------------------------------------------

## 8. THRESHOLD

*"Something irreversible is happening."*

Purpose:

-   Arrival
-   LOVE
-   Chamber
-   Memory recovery
-   Class awakening
-   Era transitions

Visual language:

-   Rare
-   Beautiful
-   Slow
-   Silence is allowed

These moments should feel ceremonial.

------------------------------------------------------------------------

# The Rule of Images

Images orient.

They do not illustrate.

  Context     Visual
  ----------- --------------
  Room        Place
  NPC         Person
  Item        Object
  Signal      Transmission
  Threshold   Ritual
  Self        No image

The absence of imagery is itself a design language.

------------------------------------------------------------------------

# The Rule of Time

The Console does not need to speak all at once.

Discord's greatest limitation becomes one of its greatest strengths.

Messages may arrive in sequence.

``` text
PLACE

...

SELF

...

WORLD

...

CHOICE
```

A scene unfolds through pacing rather than animation.

------------------------------------------------------------------------

# The Rule of Awakening

The Console matures with the player.

Early:

``` text
Place
Choice
```

Later:

``` text
Place
Self
World
Choice
```

Later:

``` text
Place
Self
Signal
Telemetry
World
Choice
```

The interface itself becomes evidence that consciousness is expanding.

------------------------------------------------------------------------

# The Rule of Mystery

The Console should never explain a mystery at the moment it is
introduced.

It should simply make the player aware that one exists.

Curiosity is stronger than instruction.

------------------------------------------------------------------------

# The Rule of Coherence

Every message should strengthen one layer of the Civilization Spine.

-   Presence
-   Memory
-   Meaning
-   Relationship
-   Coordination
-   Civilization

If a message does not strengthen one of these, ask whether it belongs.

------------------------------------------------------------------------

# Closing Observation

The player should never feel that they are reading Discord.

They should feel that they are looking through a window that is slowly
learning how to reveal the world.

The Console is not a display.

It is the first organ of consciousness shared between Future Sky and the
player.
